# Northstar Equities Prototype

A responsive, clickable equity-trading dashboard built as a standalone browser prototype.

## Open

Open `index.html` directly in a browser. No package installation, build step, or development server is required.

## Prototype interactions

- Select a stock from the market strip or a position to update its quote and chart.
- Change chart ranges, order side, order type, and share quantity.
- Submit simulated buy and sell orders to update cash, positions, and order activity.
- Browse the Overview, Portfolio, and Activity views.

All prices are sample data. Orders are simulated locally and are not sent to a broker.
